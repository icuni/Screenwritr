# Parity status and acceptance

Date: 16 October 2026. KIT Scenarist 1:1 parity remains incomplete. The upstream checklist in scenarist-parity-research.md is the reference inventory; implemented is not equivalent to accepted against the exact installed binary.

| Area | Implemented in this preview | Still requires parity work/acceptance |
| --- | --- | --- |
| Projects | Writing gallery, recent/project/recovery browser, folder indexing, native save/open, atomic recovery, backups, import archives, external-change detection | Complete upstream multi-project behavior, cloud synchronization and lossless project merging |
| Story research | Logline/synopsis/title data, hierarchical folders/notes/links/images/documents, entity profiles/aliases/custom fields | Native rich-document fidelity, galleries, complete KIT mind-map migration |
| Screenplay | Semantic paragraph types, Enter/Tab shortcuts, emphasis, scene navigation/numbers, notes/bookmarks, revisions, focus/typewriter settings | Vendor range formatting/annotations, all autocomplete behavior, production pagination/continueds, locked numbering, international templates and complete shortcut inventory |
| Cards | Synced ordering, acts, colors, synopsis, tags, stamps, keyboard/tap position editing | Native free-board geometry, exact card/print layout comparison |
| Mind maps | Original editable nodes/connections, keyboard positioning, SVG export | Vendor layout migration, all advanced map operations |
| Versions | Named snapshots, comparison, restore/copy passages | Complete upstream revision-mode and merge behavior |
| Reports | Scene/character/location breakdown, word targets, local writing sessions, CSV | Full original report catalog, production page/time fidelity |
| Interchange | KITSP/Fountain/FDX/DOCX/ODT/Trelby/desktop Celtx import, Final Cut XML and directory XML bundle outlines, common exports and source preservation | Lossless round trips and format-specific vendor extensions |
| Assistant | Active-story MCP, declared/inferred allocations, source IDs, grant/revoke, bounded reads | User's Codex/Claude client connection acceptance; write tools intentionally outside current contract |
| Creative family | Versioned graph/manifest and stable identity | Actual cross-product adapters and asset synchronization |
| Collaboration | Local authoring | Cloud coauthoring/accounts/permissions/service interoperability |
| Distribution | Validated Electron Windows executable, unsigned installer and shared-runtime ASAR | Signed release, updater, published repository and release acceptance |
| Performance | Local measurements/real-story smoke receipts | Identical-workload KIT baseline; no lighter/smoother comparison established |

The real-story compatibility corpus is kept under ignored .local/real-story-validation. It is not shipped as a demo, used to train a model, or uploaded with source. Import success checks parseability, native validation and MCP compatibility; it does not establish visual parity or lossless vendor editing.

Static target evidence identifies a native Qt x86 executable. Windows native runtime capture is unavailable in the installed REA provider, and disassembly backends are unconfigured. No original-runtime screenshot or comparative benchmark is claimed. Acceptance needs a running original-app walkthrough of the remaining checklist and matched workload measurements.
